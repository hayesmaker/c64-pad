# C64-Pad user guide

C64-Pad is a drawing app for Commodore 64 graphics: sprites, character sets
and screens. It's made for tablets with a stylus or finger, and works just as
well with a mouse on the desktop. Everything you draw stays inside what the
C64 can really show, and you can run it on a built-in C64 emulator or export
it for your own programs.

New to C64-Pad? Start with [Getting started](01-getting-started.md), then dip
into the rest as you need it.

## Quick reference

| I want to…                          | Go to                                                              |
| ----------------------------------- | ------------------------------------------------------------------ |
| Start a new project                 | My Projects → **New project**                                      |
| Switch between sprites/chars/screen | The **SPRITES / CHARS / SCREEN** tabs on the sheet's right edge    |
| Undo                                | **Undo** in the header, or Ctrl+Z (Ctrl+Y or Ctrl+Shift+Z to redo) |
| Clear one pixel                     | Double-tap it with the Draw tool                                   |
| Draw with nothing else on screen    | The **Zen mode** button in the header                              |
| See it on a real C64 (emulated)     | **Run & export** → **Run on C64**                                  |
| Get files for my assembler          | **Run & export** → **Export files**                                |
| Back up a project                   | My Projects → **⋮** → **Export**, or **Save to cloud**             |
| Draw over a photo or mock-up        | **Tracing paper** in the Sprite or Screen Worksheet header         |
